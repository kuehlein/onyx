# Topic particle 은 / 는

Marks the topic of a sentence ("as for ___").

## Rule

Use 는 after a vowel, 은 after a consonant. It attaches to the noun it marks.

## Example

저는 학생이에요 (jeoneun haksaeng-ieyo) = "As for me, I'm a student." (저 = I,
ends in a vowel → 는.)
