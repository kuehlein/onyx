# Personas

> Part of the backbone (see [index.md](index.md)). Who the stories serve. Onyx is general by
> design; SWE-interview prep (P4) is one worked example, not the product — **the same mechanism
> must serve all six with equal dignity (no privileged subject).**

- **P1 — K-12 class student.** Studies a teacher's deck via a class code; content, aims, and
  settings come pre-configured; motivation-sensitive. Pull-first; rarely authors.
- **P2 — exam / deadline student.** One or more dated tests drive pacing; wants an honest ready-by
  and a clear "what to do today". Often creates a deck from their own material.
- **P3 — open-ended hobbyist.** Korean, music theory, etc.; often **no fixed date** — the aim is
  ongoing mastery plus the contingent flows (conversation, listening tests). Values low friction.
- **P4 — SWE interviewee.** The built-in worked example: foundational concepts unlock
  algorithm + system-design + behavioral flows, with one or more dated interview loops (rounds,
  companies) as concurrent aims.
- **P5 — teacher / pusher.** Authors a deck (lens + cards + aims + config) and publishes it to a
  class or the public; cares that updates propagate **without clobbering** learners' progress.
- **P6 — professional / org onboarding.** New employees ramped onto an organization's material (a
  pushed deck + config); P1 at work scale — pull-first, **merge-not-overwrite**.
